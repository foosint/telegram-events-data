# telegram-events-data

This repository holds the published output of [telegram-events](https://github.com/foosint/telegram-events).
Each profile has its own folder. The folder is written, committed and pushed only by that profile's
`tg-events run` on the Raspberry Pi, after every run that changed the files. The Pi pushes with a
write-enabled **deploy key**.

**Setup** (deploy key, SSH clone, publishing): [SETUP.md](SETUP.md)
